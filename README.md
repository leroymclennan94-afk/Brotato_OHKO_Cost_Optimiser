# Brotato_OHKO_Cost_Optimiser
This project added a more specific level of analysis to the broader Brotato OHKO Analysis project completed previously. This project aimed to calculate what the cheapest weapon and stat build for each accuracy level was that resulted in a 95%+ chance of OHKO-ing an Elite during a standard 60 sec wave. The goal was for this information to be displayed in a figure that communciated 1) the minimum build cost for each accuracy level, and 2) the breakdown (whcih weapons and how much attack speed) of each cheapest build for a given accuracy level.

Using python, an optimisation algorithm was created to explore all possible weapon, attack speed, and accuracy combinations that result in a 95%+ OHKO chance per wave. For each accuracy level, the cheapest combination of attack speed and weapons were saved and used in the final DataFrame and visualisation. Three subplots were generated to communicate the desired information, however ideally this information could've been more concisely communicated via a tooltip feature. The tooltip feature is not supported within standard python visualisations, hence was not used for this figure.

Given the potential for developing a concise yet informative visualisation with the use of a tooltip feature, a Power BI visualisation was generated using the DataFrame created in python. This Power BI visualisation was similar to the first python subplot, howeer a detailed tooltip was introduced in Power BI to allow the simple graphic to communicate extra information. This Power BI visualisation achieved all goals of the project.
